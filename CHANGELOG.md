# Changelog

All notable changes to GitClonePro will be documented in this file.

## [2.0.0] - 2026-09-02

### Added
- Sparse checkout support (`--sparse`)
- Batch cloning with parallel threads (`--threads`)
- Mirror cloning support (`--mirror`)
- SSH key management and authentication
- Progress bars with tqdm
- Configuration file support (YAML)
- Environment variable support (`GITHUB_TOKEN`)
- Exponential backoff retry logic
- Verbose and quiet output modes
- Comprehensive logging
- Custom exceptions
- Unit tests
- Installation script

### Changed
- Complete rewrite from the ground up
- Modular architecture
- Improved error handling
- Better performance
- Enhanced documentation

### Fixed
- Rate limit handling
- Authentication issues
- Sparse checkout reliability
- Cross-platform compatibility

## [1.0.0] - 2025-01-01

### Added
- Initial release
- Basic clone functionality
- Simple CLI interface
